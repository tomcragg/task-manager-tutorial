# Task Manager Tutorial

A simple task management application built to learn Git workflows, GitHub collaboration, and CI/CD with GitHub Actions.

## Features
- Add new tasks
- Mark tasks as complete/incomplete
- Delete tasks
- Persistent storage using localStorage

## Getting Started
1. Clone the repository
2. Open `index.html` in your browser
3. Start managing your tasks!

## Development
This project is used for learning:
- Git branching strategies
- Pull request workflows
- Code review processes
- Automated testing with GitHub Actions
- Continuous Integration/Continuous Deployment

## Testing
Run tests with: `npm test` (after setting up Node.js testing environment)
